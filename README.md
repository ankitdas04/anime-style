# ⚡ Anime Cube Showcase

> A sleek 3D anime-inspired gallery that spins like a battle-ready portal.

This project brings together a rotating cube and fan-favorite anime visuals to create a stylish landing page experience using only HTML and CSS.

## ✨ What this project does

- Displays six anime-themed images on a 3D cube
- Animates the cube with a smooth rotating motion
- Creates a dynamic, immersive showcase using CSS transforms and perspective
- Keeps everything lightweight and fast without any external libraries

## 🎨 Anime vibes

The design is inspired by iconic anime energy, featuring:

- Demon Slayer

- One Piece
- Kakashi-inspired imagery
- Giyuu-inspired imagery

## 🚀 Run it locally

1. Open the project folder.
2. Double-click `index.html` in your browser, or
3. Use a live preview extension like VS Code Live Server.

The cube will automatically rotate and display the anime artwork in a 3D format.
